# CONSTRAINTS — gestureOS

> Binding constraints on the project. Each is tagged by nature:
> **[HARD]** enforced by tooling/CI, **[POLICY]** documented rule, **[ENV]** environmental,
> **[DEFERRED]** decided but not yet in force. Evidence inline.

## Runtime & platform

- **[HARD]** Python **3.14** runtime. (`DECISIONS.md` D-0003; `pyproject.toml`.)
- **[HARD]** ruff `target-version = py313` (not py314) until upstream formatter bug fixed.
  (`DECISIONS.md` D-0004; `pyproject.toml`.)
- **[POLICY]** MediaPipe **Tasks API only** — legacy `mediapipe.solutions` is removed and
  forbidden. (`DECISIONS.md` D-0003.)
- **[ENV]** Linux system libs required for MediaPipe: `libgl1 libglib2.0-0 libxcb1
  libgles2 libegl1`; baked into `Dockerfile.test`/CI. (`README.md`; `DECISIONS.md` D-0003.)
- **[POLICY]** `opencv-python-headless` (not `opencv-python`) so CI imports without an X
  server. (`DECISIONS.md` D-0003.)

## Architecture

- **[HARD]** `core/` may not import `gestureos` (import-linter forbidden contract).
  (`pyproject.toml` `[tool.importlinter]`.)
- **[POLICY]** No modality-specific type may leak into `core/`; enforced also by the
  two-fake-consumer test. (`CLAUDE.md`; `docs/architecture.md`.)
- **[DEFERRED]** `core/` is extracted to a shared library only when voiceOS becomes the
  second consumer (rule of three). (`DECISIONS.md` D-0002.)
- **[POLICY]** perception→action path uses `FastPath` (no async queue hop); the bus is
  fan-out only. (`DECISIONS.md` D-0005.)

## Performance

- **[POLICY/HARD]** Latency budget "is law": perception→action **p95 < 50 ms** per stage.
  Currently enforced only as a **glue sub-budget p95 < 5 ms** on the no-op backend until
  Step 6a real fixtures land. (`CLAUDE.md`; `benchmarks/fixtures/README.md`.)
- **[HARD]** Test coverage ≥ 80%. (`pyproject.toml`.)

## Process & workflow

- **[POLICY]** Work proceeds step-by-step per `plans/gestureos-construction.md`; one step ≈
  one PR; do not start a step whose dependencies are unmerged. (`AGENTS.md`.)
- **[HARD]** Branch model: `main` protected (no direct commits — `no-commit-to-branch`);
  typed branch prefixes; Conventional Commits (linted). (`CONTRIBUTING.md`;
  `.pre-commit-config.yaml`.) Note: chrysa canon describes `main`/`develop`; this repo's
  CONTRIBUTING branches from `main`.
- **[POLICY]** Every PR references a Shortcut story (`enforce-shortcut-link.yml`;
  `standards/rules/scm.md`).
- **[HARD]** CI required checks: `test`, `sonar`. Lint runs in pre-commit + at release.
  (`.github/workflows/ci.yml`.)
- **[POLICY]** Tests/lint never on host — Docker or pre-commit only. (See `TRD.md` §4 for
  the Makefile contradiction.)

## Language & documentation

- **[POLICY]** All committed code, comments, docs and config in **English**; context files
  are generated (regenerate, do not hand-edit `handover.md`, `ai-instructions.md`,
  `context-map.json`, `llms-full.txt`). (`CONTRIBUTING.md`; `scripts/gen_context_files.py`.)

## chrysa canon

- **[POLICY]** The repo adheres to chrysa transverse standards; the canon wins over any
  annexe. Managed blocks in `CLAUDE.md` / `AGENTS.md` are generated by
  `distribute-standards.sh` and must not be hand-edited. (`DECISIONS.md` D-0001;
  `standards/`.)
